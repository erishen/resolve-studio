# Sandbox Directory

This directory is the default workspace for files generated by the agent's `write-file` tool.

- Relative paths in `write-file` resolve here (e.g. `foo.py` → `sandbox/foo.py`).
- Use absolute paths to write outside this directory (still requires human approval).
- Contents can be safely deleted — they are scratch work, not project source.
- The OS-level sandbox (macOS Seatbelt / Linux bwrap) also restricts shell command writes to this directory + the project root + the system temp directory.
